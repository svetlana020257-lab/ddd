# Касса Art Mosaic + бот Феня

Учёт доходов и расходов мастерской: веб-приложение (телефон и компьютер), Google Таблица и Telegram-бот «Феня».
Всё работает внутри **Google Apps Script**, а не на GitHub Pages: здесь лежат исходники и резервная копия.

## Файлы

| Файл | Куда в Apps Script | Что это |
|---|---|---|
| `Code.gs` | файл «Код» | таблица (листы, оформление, дашборд) и API приложения |
| `Index.html` | — (уже встроен в `Code.gs`) | исходник страницы приложения; после правок пересобрать в константу `INDEX_HTML` в конце `Code.gs` |
| `Bot.gs` | скрипт `Bot` (или «Феня») | Telegram-бот Феня |
| `fenya_avatar_512.png` | @BotFather → `/setuserpic` | аватарка бота |
| `fenya_1024.png` | — | Феня крупно, для соцсетей и печати |

## Секреты не в репозитории

В `Bot.gs` здесь **пустые** `BOT_TOKEN` и `ALLOWED_IDS`. Рабочие значения хранятся только в проекте Apps Script.
При обновлении кода из репозитория не затирайте эти две строки в Apps Script.

## Установка с нуля

1. Google Таблица → Расширения → Apps Script → вставить `Code.gs` в «Код» и создать скрипт `Bot` с `Bot.gs`. HTML-файл не нужен.
2. Запустить `setup` — создаст и оформит листы: Дашборд, Операции, Категории, Сводка, Платежи, Дела, Абонементы, Посещения.
3. Начать развертывание → Новое развертывание → Веб-приложение. Запуск от имени: «Я», доступ: «Все».
4. В `Bot.gs` вписать `BOT_TOKEN`, `WEBAPP_URL` (ссылка `/exec`), `ALLOWED_IDS` → «Новая версия» → запустить `setupBot`.
5. Проверка бота — функция `checkBot` (журнал выполнения).
6. Календарь: запустить `setupCalendar` — создаст календарь «Art Mosaic · Феня», перенесёт платежи и дела со сроком. Поделиться им с Галиной в настройках Google Календаря.

## Обновление кода

Заменить файлы → «Управление развертываниями» → карандаш → **Новая версия** → «Развернуть». Ссылка не меняется.
После изменений в оформлении таблицы — ещё раз `setup` (записи не стираются, «Сводка» и «Дашборд» пересобираются).

Функцию `doPost` руками не запускать — её вызывает Telegram.

## Абонементы

Вкладка «Абонем.» в приложении. Абонемент — клиент, сколько часов, срок действия, стоимость.
Каждое занятие («− занятие») пишется строкой в лист «Посещения» и списывает часы.
В листе «Абонементы» «Израсходовано», «Осталось» и «Статус» считаются формулами — видно и без приложения.
При создании можно сразу записать оплату в доходы (категория «Абонемент») и указать часы, потраченные до начала учёта.
Листы создаются сами при первом открытии приложения после обновления.

На вкладке «Итоги» внизу — ссылки на все приложения мастерской (сертификаты, приглашения, каталог, сайт).
